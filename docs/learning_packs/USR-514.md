# USR-514 — SOPS e age no Windows

O manual agora procura pacotes WinGet nos escopos de usuário e máquina. Antes de ajustar o PATH, valida cada executável encontrado pelo caminho completo. Depois acrescenta ao PATH do usuário apenas diretórios ausentes, sem usar `setx PATH`; após reabrir o PowerShell, o operador confirma `sops`, `age` e `age-keygen` e suas versões.

Validação desta correção: os seis blocos PowerShell do manual passaram pelo parser; `python -m pytest tests/test_docs_sync.py -q` passou (6 testes, 11,19 s). O portão oficial `runner.py --quick` recusou executar por a worktree estar suja (`docs/manual/segredos.md`); não houve commit conforme instruído.

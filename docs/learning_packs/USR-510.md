# USR-510 — Admissão não herda o pin de um único worker

## T2 — O pin do host não esconde os outros workers

`default_launch` continua fixando o portão no worker do host. No filho, `DARKFAC_TEST_WORKERS` fica só com a URL desse host, junto com `DARKFAC_REMOTE_HARNESS=required` e `DARKFAC_FLEET_GATE_REMOTE=1`.

A admissão não lê esse pin. O mesmo filho recebe `DARKFAC_ADMISSION_WORKERS` com a lista que já estava em `DARKFAC_TEST_WORKERS` no despachante. Se essa lista estava vazia, entra o default grokbox+desktop (`http://100.77.130.5:8080,http://100.78.181.90:8080`). A URL do pin é acrescentada se ainda não estava na lista. URL repetida fica uma vez.

No Notebook, host sem `worker_url`, o filho segue com `DARKFAC_REMOTE_HARNESS=off` e `DARKFAC_TEST_WORKERS` não é substituído.

O pin de execução não é a lista que a admissão lê.

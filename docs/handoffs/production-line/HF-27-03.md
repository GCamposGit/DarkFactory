# HF-27-03 — AgentCLI real + roteamento por quota

Papel: economy · Depende de: — · Resolve: D3, D9.

## Objetivo
Uma função que roda um agente de código **de verdade** (modo escrita, cwd do projeto, modelo escolhido), mede o uso e escolhe a conta conforme a política "assinatura primeiro, OpenRouter só em nível crítico".

## 1. `core/line/agent_cli.py` (novo)
```python
class AgentRequest(BaseModel):
    prompt: str; cwd: Path; mode: Literal["write","read"]; harness: str; model: str | None
    effort: str | None; timeout_s: int = 1800; max_turns: int | None = None
class AgentResult(BaseModel):
    ok: bool; text: str; harness: str; model: str | None; duration_s: float
    usage: dict | None; cost_usd: float | None; error_kind: Literal[None,"rate_limited","auth_expired","not_installed","timeout","crash"]
    reset_at: datetime | None
def run_agent(req: AgentRequest) -> AgentResult
```
Invocações (lista de args, sem `shell=True`, prompt via stdin quando suportado):
- **claude:** `claude -p --output-format json --model <m> --permission-mode bypassPermissions` (write) ou `--permission-mode plan` (read), com `--max-turns` se definido. O JSON traz `result`, `total_cost_usd`, `usage` e `is_error`.
- **codex:** `codex exec --sandbox workspace-write --skip-git-repo-check --json -m <m> -o <tmpfile> -` (write) ou `--sandbox read-only` (read).
- **grok / antigravity:** reaproveitar os finders e comandos de `core/harness/remote_worker.py`. Se não houver modo escrita headless confiável, registrar a capacidade como `read` apenas.
- **openrouter:** só em `mode="read"` (review, grill, distill), via `core/execution/providers.py` existente.
- Classificação de erro por regex no stderr/JSON: `rate limit|usage limit|429` → `rate_limited` (extrair o reset quando houver); `login|unauthorized|401|expired` → `auth_expired`.

Ajuste mínimo em `core/harness/remote_worker.py`: aceitar `mode` no request e usar as mesmas flags acima. Hoje o Codex está fixo em `read-only` e o Claude sem permission mode. O endpoint continua existindo para uso ad hoc, mas a linha usa execução local no worker (ver HF-27-09).

## 2. `core/line/routing.py` (novo) + `.factory/config/line_routing.json` (novo)
```json
{
  "pressure_thresholds": {"guarded": 50, "stressed": 25, "critical": 10},
  "cooldown_default_minutes": 60,
  "stages": {
    "grill":       {"cascade": [["claude","sonnet"],["codex",null]], "openrouter_ok": true,  "openrouter_model": "<barato>"},
    "planning":    {"cascade": [["claude","opus"],["codex",null]],   "effort": "high", "openrouter_ok": false},
    "development": {"cascade": [["claude","sonnet"],["codex",null],["grok",null],["antigravity",null]], "openrouter_ok": false},
    "review":      {"cascade": "other_family_than_development", "openrouter_ok": true, "openrouter_model": "<barato-outra-família>"},
    "distill":     {"cascade": [], "openrouter_ok": true, "local_ok": true}
  },
  "run_caps": {"agent_calls": 14, "validate_iterations_per_ticket": 3, "review_rounds": 2, "wall_clock_hours": 6, "openrouter_usd": 2.0}
}
```
- Os limiares default são **os mesmos da v0** em `core/router/token_budget.py::_pressure_for` e devem ser lidos de lá quando o arquivo não existir.
- `pick(stage, host_caps, exclude) -> (harness, model) | None`: percorre a cascata e pula harness sem capability no host, conta em cooldown ou conta com pressão `critical` (quota lida por `core/usage/adapters.py` quando disponível; Codex tem leitura real, Claude Pro pode ser `unknown`, que conta como elegível). OpenRouter entra só se `openrouter_ok` **ou** se todas as contas da cascata estiverem `critical`/cooldown, respeitando `run_caps.openrouter_usd`.
- Cooldown persistido no control store, ou em `.factory/usage/cooldowns.json` se o store não tiver tabela. É gravado quando `AgentResult.error_kind == "rate_limited"` (até `reset_at` ou o default).
- `pick` retorna `None` quando não há conta elegível. A etapa devolve `retry` com `not_before = menor reset`, e não falha.

## Aceite
- Com CLIs falsos no PATH: modo write passa as flags corretas, `cwd` é respeitado e o JSON do Claude é parseado (custo/uso).
- `rate_limited` coloca a conta em cooldown e a próxima chamada escolhe o próximo da cascata.
- Com todos em cooldown: `development` retorna `None`, e `review` retorna OpenRouter.
- Editar `line_routing.json` muda a cascata sem alterar código.

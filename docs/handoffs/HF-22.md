## 2. Decisões do Grill (Alinhamento Estruturado)

1. **Zero Reinvenção**: O Segundo Cérebro já é um projeto maduro e operacional em `C:\dev\SegundoCerebro`. A Dark Factory e o Jarvis apenas consultam suas capacidades via conector MCP nativo (`py -m segundocerebro.mcp.server`).
2. **Ingestão Multimodal**: Suporte para documentos Office padrão (`.docx`, `.xlsx`, `.pptx`), documentos (`.pdf`, `.md`, `.txt`) e transcrições de áudio.
3. **Segregação Multi-Projeto**: Namespacing por `project_id` (`darkfac`, `atrium`, `jarvis`), com base comum global (`shared`).
4. **Proveniência Estrita & Anti-Alucinação (Fail-Closed)**: Rejeição determinística de alucinações. Passagens abaixo do limiar de relevância são descartadas; consultas sem evidências suficientes retornam explicitamente `INSUFFICIENT_EVIDENCE`.

---

## 3. Escopo Entregue

1. **Contratos Pydantic v2 (`core/knowledge/models.py`)**:
   - `KnowledgeQuery`: query, `project_id`, `k`, `min_score`, `include_neighbors`, `root_folder`.
   - `KnowledgeCitation`: `id`, `file_path`, `section`, `locator`, `content`, `score`, `provenance_hash`, `project_id`.
   - `KnowledgeQueryResult`: status (`FOUND` | `INSUFFICIENT_EVIDENCE`), citations, execution_time_ms.
   - `IngestionRequest` & `IngestionResult`: validação e staging de arquivos.
   - `SecondBrainStatus`: diagnóstico de saúde do servidor MCP.
2. **Cliente Headless MCP (`core/knowledge/segundo_cerebro_client.py`)**:
   - Conexão direta com `C:\dev\SegundoCerebro`.
   - Normalização matemática transparente de scores RRF e densos.
   - Enforçamento de proveniência Fail-Closed e segregação de tenants.
   - Suporte a modo offline/mock para testes determinísticos rápidos.
3. **Despachante de Ingestão (`core/knowledge/ingestor.py`)**:
   - Suporte para `.docx`, `.xlsx`, `.pptx`, `.pdf`, `.md`, `.txt` e áudios.
   - Cálculo de hash SHA-256 e staging na partição do corpus do projeto.
4. **Interface CLI Headless (`core/knowledge/cli.py`)**:
   - `status`, `search`, `read`, `ingest`.
5. **Skill 18 no Catálogo Canônico (`.agents/skills/18-second-brain-knowledge/SKILL.md`)**:
   - Registrada e sincronizada com `.claude/skills/18-second-brain-knowledge/`.
6. **Suíte de Testes Automatizados (`tests/test_segundo_cerebro_connector.py`)**:
   - 8 testes unitários e de integração (100% verde).

## 5. Instruções de Operação para o Usuário e Agentes

Para consultar o acervo com segregação por projeto:
```powershell
python C:\dev\DarkFac\core\knowledge\cli.py search "sua dúvida" --project jarvis
```

Para verificar o status do servidor MCP do Segundo Cérebro:
```powershell
python C:\dev\DarkFac\core\knowledge\cli.py status
```

Para ingerir um documento Office (Word, Excel ou PowerPoint) no acervo de um projeto:
```powershell
python C:\dev\DarkFac\core\knowledge\cli.py ingest C:\caminho\arquivo.docx --project jarvis
python C:\dev\DarkFac\core\knowledge\cli.py ingest C:\caminho\planilha.xlsx --project atrium
python C:\dev\DarkFac\core\knowledge\cli.py ingest C:\caminho\apresentacao.pptx --project darkfac
```

# Qualificação isolada de robustez

## Problema
Construir e executar uma qualificação isolada do ciclo integrado cobrindo concorrência, replay, retomada, perda de host com fencing, consolidação de janelas atrasadas, piso de cota, falta de capacidade e desativação de domínio. Persistir uma matriz que comprove cobertura, custo e adiamento distintos, sem usar a simulação como substituta da prova operacional real.
